# 🟡 49. Group Anagrams

## 📌 Problem Statement

Given an array of strings `strs`, group the anagrams together.

You may return the answer in **any order**.

An **anagram** is a word formed by rearranging the letters of another word.

---

## 🧾 Examples

### Example 1
```
Input: strs = ["eat","tea","tan","ate","nat","bat"]
Output: [["bat"],["nat","tan"],["ate","eat","tea"]]
```

### Example 2
```
Input: strs = [""]
Output: [[""]]
```

### Example 3
```
Input: strs = ["a"]
Output: [["a"]]
```

---

## 🔒 Constraints

- `1 <= strs.length <= 10^4`
- `0 <= strs[i].length <= 100`
- `strs[i]` consists of lowercase English letters.

---

# 🚀 Approach 1: Sorting Each String

## 💡 Idea

If two words are anagrams:
- After sorting their characters,
- They become identical.

Use the sorted string as a key in a dictionary.

---

## 🧑‍💻 Python Code

```python
class Solution:
    def groupAnagrams(self, strs: list[str]) -> list[list[str]]:
        groups = {}
        
        for word in strs:
            key = "".join(sorted(word))
            
            if key not in groups:
                groups[key] = []
            
            groups[key].append(word)
        
        return list(groups.values())
```

---

## ⏱ Complexity

- Time: **O(n * k log k)**  
  (n = number of strings, k = max length of string)
- Space: **O(nk)**

⚠️ Sorting each string costs `k log k`.

---

# 🚀 Approach 2: Optimal Solution (Character Frequency Count) ✅

## 💡 Idea

Instead of sorting:

1. Create a frequency array of size 26 for each word.
2. Convert it to a tuple (so it can be a dictionary key).
3. Use this tuple as the key.

Since counting is O(k), this avoids sorting.

---

## 🧑‍💻 Python Code

```python
class Solution:
    def groupAnagrams(self, strs: list[str]) -> list[list[str]]:
        groups = {}
        
        for word in strs:
            count = [0] * 26
            
            for char in word:
                count[ord(char) - ord('a')] += 1
            
            key = tuple(count)
            
            if key not in groups:
                groups[key] = []
            
            groups[key].append(word)
        
        return list(groups.values())
```

---

## ⏱ Complexity (Optimal)

- Time: **O(n * k)**
- Space: **O(nk)**

✅ Faster than sorting approach for large inputs.

---

# 📚 Key Takeaways

- Anagrams share identical character frequencies.
- Sorting works but is slower (`k log k`).
- Frequency counting gives linear time per string.
- Tuple keys allow lists to be used as dictionary keys.
