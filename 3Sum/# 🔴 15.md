# 🔴 15. 3Sum

## 📌 Problem Statement

Given an integer array `nums`, return all the triplets  
`[nums[i], nums[j], nums[k]]` such that:

- `i != j`
- `i != k`
- `j != k`
- `nums[i] + nums[j] + nums[k] == 0`

The solution set must **not contain duplicate triplets**.

You may return the answer in any order.

---

## 🧾 Examples

### Example 1
```
Input: nums = [-1,0,1,2,-1,-4]
Output: [[-1,-1,2],[-1,0,1]]
```

### Example 2
```
Input: nums = [0,1,1]
Output: []
```

### Example 3
```
Input: nums = [0,0,0]
Output: [[0,0,0]]
```

---

## 🔒 Constraints

- `3 <= nums.length <= 3000`
- `-10^5 <= nums[i] <= 10^5`

---

# 🚀 Approach 1: Brute Force

## 💡 Idea

Check every combination of three numbers.

---

## 🧑‍💻 Python Code

```python
class Solution:
    def threeSum(self, nums: list[int]) -> list[list[int]]:
        n = len(nums)
        result = set()
        
        for i in range(n):
            for j in range(i + 1, n):
                for k in range(j + 1, n):
                    if nums[i] + nums[j] + nums[k] == 0:
                        triplet = tuple(sorted([nums[i], nums[j], nums[k]]))
                        result.add(triplet)
        
        return [list(triplet) for triplet in result]
```

---

## ⏱ Complexity

- Time: **O(n³)**
- Space: **O(n)**

⚠️ Too slow for large inputs.

---

# 🚀 Approach 2: Optimal Solution (Sorting + Two Pointers) ✅

## 💡 Key Insight

1. Sort the array.
2. Fix one element.
3. Use two pointers (`left`, `right`) to find pairs that sum to `-nums[i]`.
4. Skip duplicates carefully.

---

## 🧠 Algorithm

1. Sort `nums`.
2. Loop `i` from 0 to n-1:
   - Skip duplicate values of `nums[i]`.
   - Set `left = i + 1`, `right = n - 1`.
   - While `left < right`:
     - If sum == 0 → add triplet.
     - Move pointers.
     - Skip duplicates.

---

## 🧑‍💻 Python Code

```python
class Solution:
    def threeSum(self, nums: list[int]) -> list[list[int]]:
        nums.sort()
        result = []
        n = len(nums)
        
        for i in range(n):
            # Skip duplicate fixed elements
            if i > 0 and nums[i] == nums[i - 1]:
                continue
            
            left = i + 1
            right = n - 1
            
            while left < right:
                total = nums[i] + nums[left] + nums[right]
                
                if total == 0:
                    result.append([nums[i], nums[left], nums[right]])
                    left += 1
                    right -= 1
                    
                    # Skip duplicate left values
                    while left < right and nums[left] == nums[left - 1]:
                        left += 1
                    
                    # Skip duplicate right values
                    while left < right and nums[right] == nums[right + 1]:
                        right -= 1
                
                elif total < 0:
                    left += 1
                else:
                    right -= 1
        
        return result
```

---

## ⏱ Complexity (Optimal)

- Time: **O(n²)**
- Space: **O(1)** (excluding output)

✅ Much faster than O(n³)  
✅ Handles duplicates correctly  

---

# 📚 Key Takeaways

- Sorting enables two-pointer strategy.
- Always skip duplicates to avoid repeated triplets.
- Pattern builds directly on **Two Sum**.
- Very common FAANG interview problem.
