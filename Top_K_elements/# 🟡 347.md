# 🟡 347. Top K Frequent Elements

## 📌 Problem Statement

Given an integer array `nums` and an integer `k`, return the `k` most frequent elements.

You may return the answer in **any order**.

---

## 🧾 Examples

### Example 1
```
Input: nums = [1,1,1,2,2,3], k = 2
Output: [1,2]
```

### Example 2
```
Input: nums = [1], k = 1
Output: [1]
```

### Example 3
```
Input: nums = [1,2,1,2,1,2,3,1,3,2], k = 2
Output: [1,2]
```

---

## 🔒 Constraints

- `1 <= nums.length <= 10^5`
- `-10^4 <= nums[i] <= 10^4`
- `k` is in the range `[1, number of unique elements]`
- The answer is guaranteed to be unique.

---

# 🚀 Approach 1: Brute Force (Sorting)

## 💡 Idea

1. Count frequency using a dictionary.
2. Sort elements by frequency.
3. Return first `k` elements.

---

## 🧑‍💻 Python Code

```python
class Solution:
    def topKFrequent(self, nums: list[int], k: int) -> list[int]:
        count = {}
        
        for num in nums:
            count[num] = count.get(num, 0) + 1
        
        sorted_items = sorted(count.items(), key=lambda x: x[1], reverse=True)
        
        result = []
        for i in range(k):
            result.append(sorted_items[i][0])
        
        return result
```

---

## ⏱ Complexity

- Time: **O(n log n)** (due to sorting)
- Space: **O(n)**

⚠️ Does NOT satisfy follow-up requirement.

---

# 🚀 Approach 2: Min Heap (Better)

## 💡 Idea

- Count frequencies.
- Use a heap to extract top `k` elements.

---

## 🧑‍💻 Python Code

```python
import heapq

class Solution:
    def topKFrequent(self, nums: list[int], k: int) -> list[int]:
        count = {}
        
        for num in nums:
            count[num] = count.get(num, 0) + 1
        
        heap = []
        for num, freq in count.items():
            heapq.heappush(heap, (-freq, num))
        
        result = []
        for _ in range(k):
            result.append(heapq.heappop(heap)[1])
        
        return result
```

---

## ⏱ Complexity

- Time: **O(n log n)**
- Space: **O(n)**

---

# 🚀 Approach 3: Optimal Solution (Bucket Sort) ✅

## 💡 Idea

Instead of sorting:

1. Count frequencies.
2. Create buckets where index = frequency.
3. Place numbers in corresponding bucket.
4. Traverse buckets from high frequency to low.
5. Collect first `k` elements.

Since max frequency ≤ `n`, this avoids sorting.

---

## 🧑‍💻 Python Code

```python
class Solution:
    def topKFrequent(self, nums: list[int], k: int) -> list[int]:
        count = {}
        
        # Step 1: Count frequency
        for num in nums:
            count[num] = count.get(num, 0) + 1
        
        # Step 2: Create buckets
        buckets = [[] for _ in range(len(nums) + 1)]
        
        for num, freq in count.items():
            buckets[freq].append(num)
        
        # Step 3: Gather top k elements
        result = []
        
        for freq in range(len(buckets) - 1, 0, -1):
            for num in buckets[freq]:
                result.append(num)
                if len(result) == k:
                    return result
```

---

## ⏱ Complexity (Optimal)

- Time: **O(n)**
- Space: **O(n)**

✅ Satisfies follow-up requirement (better than O(n log n))

---

# 📚 Key Takeaways

- Sorting → O(n log n)
- Heap → O(n log n)
- Bucket Sort → O(n) 🚀
- Frequency counting + smart grouping avoids expensive sorting.
