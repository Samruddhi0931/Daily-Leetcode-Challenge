# 🟡 238. Product of Array Except Self

## 📌 Problem Statement

Given an integer array `nums`, return an array `output` such that:

```
output[i] = product of all elements of nums except nums[i]
```

- Each product is guaranteed to fit in a 32-bit integer.
- You must solve it in **O(n)** time.
- You cannot use the division operation (follow-up requirement).

---

## 🧾 Examples

### Example 1
```
Input: nums = [1,2,4,6]
Output: [48,24,12,8]
```

### Example 2
```
Input: nums = [-1,0,1,2,3]
Output: [0,-6,0,0,0]
```

---

## 🔒 Constraints

- `2 <= nums.length <= 1000`
- `-20 <= nums[i] <= 20`

---

# 🚀 Approach 1: Brute Force

## 💡 Idea

For each index:
- Multiply all elements except itself.

---

## 🧑‍💻 Python Code

```python
class Solution:
    def productExceptSelf(self, nums: list[int]) -> list[int]:
        n = len(nums)
        result = []
        
        for i in range(n):
            product = 1
            for j in range(n):
                if i != j:
                    product *= nums[j]
            result.append(product)
        
        return result
```

---

## ⏱ Complexity

- Time: **O(n²)**
- Space: **O(1)**

⚠️ Too slow for large inputs.

---

# 🚀 Approach 2: Using Division (Not Allowed in Follow-up)

## 💡 Idea

1. Multiply all elements.
2. Divide total product by each element.

⚠️ Fails when zeros are present.
⚠️ Not allowed per follow-up requirement.

---

## 🧑‍💻 Python Code

```python
class Solution:
    def productExceptSelf(self, nums: list[int]) -> list[int]:
        total_product = 1
        
        for num in nums:
            total_product *= num
        
        return [total_product // num for num in nums]
```

---

## ⏱ Complexity

- Time: **O(n)**
- Space: **O(1)**

⚠️ Not valid for this problem.

---

# 🚀 Approach 3: Optimal Solution (Prefix + Postfix Products) ✅

## 💡 Key Insight

For each index:

```
result[i] = (product of all elements to the left)
            *
            (product of all elements to the right)
```

We can compute:
- Prefix products (left to right)
- Postfix products (right to left)

Without using division.

---

## 🧠 Algorithm

1. Create result array initialized with 1.
2. Traverse left → compute prefix product.
3. Traverse right → multiply postfix product.
4. Return result.

---

## 🧑‍💻 Python Code

```python
class Solution:
    def productExceptSelf(self, nums: list[int]) -> list[int]:
        n = len(nums)
        result = [1] * n
        
        # Prefix pass
        prefix = 1
        for i in range(n):
            result[i] = prefix
            prefix *= nums[i]
        
        # Postfix pass
        postfix = 1
        for i in range(n - 1, -1, -1):
            result[i] *= postfix
            postfix *= nums[i]
        
        return result
```

---

## ⏱ Complexity (Optimal)

- Time: **O(n)**
- Space: **O(1)** (excluding output array)

✅ Meets follow-up requirement  
✅ No division used  
✅ Handles zeros correctly  

---

# 📚 Key Takeaways

- Brute force → O(n²)
- Division approach → not allowed
- Prefix + Postfix trick → O(n)
- Very common interview pattern
- Think in terms of left-product × right-product
